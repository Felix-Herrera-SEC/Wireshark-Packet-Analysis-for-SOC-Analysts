# 🦈 Lab 02 Wireshark Display Filters & Traffic Isolation

## Objective
Capture and analyze network traffic using Wireshark display filters to isolate relevant packets by protocol, IP address, TCP/UDP port, packet attributes, and combined filtering conditions.


## Skills Demonstrated
Wireshark packet capture and traffic isolation

Protocol-based display filtering

Source and destination IP filtering

TCP and UDP port filtering

Compound filters using logical operators

DNS query filtering

TCP flag inspection

HTTP and TLS traffic identification

Network indicator extraction

SOC alert triage and documentation



## Tools used
Wireshark

Ubuntu Linux

Bash

ping

dig

curl



## Steps performed
Captured controlled ICMP, DNS, TCP, and TLS traffic.

Applied protocol-specific display filters.

Isolated packets by source and destination IP.

Filtered traffic by TCP and UDP ports.

Used logical operators to combine filter conditions.

Inspected packet attributes, including TCP flags and DNS query names.

Extracted network indicators from filtered traffic.

Completed a simulated SOC traffic isolation investigation.

## SOC relevance 
SOC analysts use packet filtering to investigate alerts, isolate suspicious hosts, identify network services, correlate indicators, and reduce large packet captures to relevant evidence.

Effective filtering accelerates alert triage and helps analysts distinguish observed network behavior from unsupported assumptions.
